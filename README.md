<h1 align="center">Unlock</h1>

<p align="center">
  Простое приложение для Windows: включает DPI-обход, помогает открыть Telegram и управляет собственными списками сайтов.
</p>

## Что умеет

- Один переключатель для запуска и остановки обхода.
- Готовые профили `zapret` / `winws` для разных провайдеров и типов блокировок.
- Игровой режим: расширяет фильтр на игровые порты и голосовой чат.
- Менеджер доменов, IP-адресов и подсетей. Изменения применяются без перезапуска всего приложения.
- AI DNS для ChatGPT, Claude, Gemini и других сервисов: hosts-набор и DNS `dns.malw.link` включаются одной кнопкой.
- Telegram Desktop через локальный MTProto → WebSocket bridge; ссылка на прокси предлагается автоматически.
- Выбор профиля в окне или в трее: новый профиль сразу включается, а работающий `winws` перезапускается только при необходимости.
- Автозапуск вместе с Windows, запуск в трей, русский и английский языки, журнал событий и проверка актуального пакета Zapret.

## Быстрый старт

1. Откройте [Releases](../../releases) и скачайте `Unlock.zip` или установщик.
2. Распакуйте ZIP в отдельную папку и запустите `Unlock.exe`.
3. Подтвердите запрос администратора. Это нужно `winws` для работы с WinDivert.
4. На главном экране выберите профиль, если нужно, и нажмите большую кнопку.
5. Если сервис всё ещё недоступен, попробуйте другой DPI-профиль в настройках или меню значка в трее.

Приложение само сохраняет выбранный профиль и пользовательские списки. При следующем запуске не нужно настраивать всё заново.

## Списки сайтов и IP

Откройте раздел **«Списки»** и добавьте домен, IP-адрес или подсеть вручную либо импортируйте файл.

Поддерживаются обычные форматы:

```text
example.com
*.example.org
203.0.113.10
203.0.113.0/24
0.0.0.0 blocked.example # строки из hosts/adblock-списка тоже подходят
```

После сохранения работающий DPI-движок перезапустится сам. Ваши правила лежат отдельно от пакета Zapret в `%APPDATA%\Unlock\zapret-lists`, поэтому обновление приложения их не удаляет.

## AI DNS

Переключатель **AI services** находится в разделе «Списки».

При включении Unlock:

1. загружает полный hosts-набор `dns.malw.link` и дополнение Goida-AI-Unlocker;
2. записывает его только между маркерами `# Unlock AI services BEGIN/END` в Windows `hosts`;
3. сохраняет текущие DNS активных сетевых адаптеров и устанавливает DNS `dns.malw.link` для IPv4 и IPv6.

При выключении удаляется только собственный блок Unlock, а прежние DNS-настройки восстанавливаются. Другие записи в `hosts` не изменяются. Windows попросит подтверждение администратора; антивирус может показать предупреждение из-за законного изменения `hosts`.

## Telegram

Когда обход включён, Unlock поднимает локальный прокси на `127.0.0.1:1443` и предлагает его Telegram Desktop. Подтвердите предложение Telegram один раз. Если клиент был закрыт, нажмите карточку Telegram на главной странице, чтобы предложить прокси повторно.

## Обновления и безопасность

При запуске Unlock проверяет актуальный пакет [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube/releases/latest). Новый пакет устанавливается только после проверки структуры архива; если сеть недоступна, используется последняя рабочая локальная копия.

Не скачивайте исполняемые файлы из комментариев, файлообменников и сторонних сборок. Для приложения используйте только страницу [Releases](../../releases) этого репозитория.

## Если что-то не работает

- Запустите Unlock от имени администратора и посмотрите «Журнал» — там указана конкретная причина ошибки.
- Переключите DPI-профиль; разные сети блокируют трафик по-разному.
- Для проблемного сайта добавьте домен в «Списки» и включите обход снова.
- Если не запускается Telegram, убедитесь, что порт `1443` не занят другой программой.
- Если AI DNS не включается, подтвердите UAC и временно разрешите изменение `hosts` в антивирусе.

## Системные требования

- Windows 10/11, 64-bit;
- права администратора для DPI-обхода и AI DNS;
- доступ к GitHub при первом обновлении пакета Zapret.

