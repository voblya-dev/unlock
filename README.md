# Unlock

![Unlock](assets/unlock-white.png)

**Unlock** - Windows-приложение для управления обходом DPI, локальным прокси Telegram и собственными VPN-подключениями из одного аккуратного интерфейса.

Программа рассчитана на сценарий, когда пользователю нужен понятный переключатель для сети, автоматический подбор рабочей стратегии и отдельный VPN с поддержкой UDP, игр и приложений, которые игнорируют системный прокси.

## Возможности

| Область | Что умеет Unlock |
| --- | --- |
| Обход DPI | Запускает встроенный `winws.exe` с готовыми конфигурациями zapret и hostlist-файлами |
| Telegram | Поднимает локальный MTProto WebSocket-мост, создаёт `tg://` ссылку и предлагает прокси запущенному Telegram Desktop |
| Fake TLS | Может маскировать handshake Telegram под обычный HTTPS и показывать реальный HTTPS-сайт незнакомым клиентам |
| VPN | Импортирует серверы и запускает VPN отдельно от DPI и Telegram |
| TUN | Направляет через виртуальный адаптер приложения без поддержки системного прокси, включая UDP, игры и QUIC |
| Автоподбор | Проверяет стратегии на Discord, YouTube, Google и Cloudflare через HTTP/1.1, TLS 1.2 и TLS 1.3 |
| Генетический поиск | Собирает и сохраняет стратегию, оптимизированную под конкретного провайдера |
| Игровой режим | Расширяет фильтр на диапазон портов `1024-65535` |
| Интерфейс | Вкладки Home, VPN, Settings и Logs, системный трей, две темы, два языка, акценты и анимации |
| Надёжность | Одна копия приложения, фоновые потоки, восстановление системного прокси после аварийного завершения |

## Интерфейс

### Home

- Главная кнопка запускает или останавливает выбранные движки обхода.
- На экране видны состояние, активная DPI-стратегия, задержка, состояние Telegram и статистика трафика.
- Переключатель Game mode можно менять прямо на главном экране.
- Кнопка Re-test / Benchmark запускает повторный тест стратегий.
- Если Telegram уже запущен, Unlock может повторно предложить ему локальный прокси.

### VPN

- Список сохранённых серверов с отдельным состоянием каждого профиля.
- Кнопка добавления профиля и drag-and-drop для файлов и изображений с QR-кодом.
- Проверка задержки до активного сервера.
- Независимый переключатель VPN. DPI и Telegram могут работать отдельно от туннеля.
- Быстрое переключение на другой сервер с переподключением без ручной остановки.
- Отображение отправленных и полученных байтов.

### Settings

Настройки сгруппированы по назначению:

#### Внешний вид

- Следовать системной теме Windows.
- Тёмная тема.
- Светлая тема.
- Монохромный белый акцент по умолчанию и дополнительные цветовые акценты.
- Пользовательские цвета через HEX/HSV-пикер.
- Английский или русский язык, либо автоматический выбор по языку Windows.

#### Запуск

- Запускать Unlock вместе с Windows для текущего пользователя.
- Запускать свёрнутым в системный трей.
- Автоматически включать обход после запуска.
- Автоматически включать выбранный VPN-сервер после запуска.
- Звуковой сигнал при подключении и отключении.
- Автоматический повторный тест через выбранное количество дней.

#### Движки обхода

- DPI bypass для YouTube, Discord и HTTPS-сайтов.
- WebSocket bridge для Telegram.
- Автоматически передавать прокси запущенному Telegram.
- Fake TLS для Telegram.
- Выбор стратегии вручную или режим Auto по последнему benchmark.
- Запуск эволюции стратегии для текущего подключения.

#### VPN

- TUN-режим для маршрутизации всего трафика через виртуальный адаптер.
- Направление системного прокси Windows на локальный VPN-порт.
- Эти параметры можно включать независимо друг от друга.

### Logs

Живой журнал событий с очисткой окна. Подробный файл лога сохраняется отдельно и помогает диагностировать ошибки драйвера, прокси, VPN и импорта конфигураций.

### Системный трей

Из меню трея доступны:

- Connect или Disconnect для основного обхода.
- Connect VPN или Disconnect VPN.
- Показать окно.
- Повторный benchmark.
- Эволюция стратегии.
- Полный выход из приложения.

Закрытие окна не завершает Unlock: приложение продолжает работать в трее.

## Как работает основной обход

Основная кнопка управляет двумя независимыми компонентами:

```text
Unlock
  |
  +-- winws.exe + WinDivert  -> обработка DPI-трафика
  |
  +-- tg-ws-proxy            -> локальный MTProto/WebSocket-мост Telegram
```

Можно включить только один из компонентов или оба сразу. Если DPI включён, Windows требует запуск с правами администратора для загрузки WinDivert. Telegram-мост работает на локальном порту `127.0.0.1:1443`.

Состояния отображаются отдельно и не блокируют интерфейс во время запуска:

- `IDLE` - ожидание.
- `CONNECTING` - движки запускаются.
- `ACTIVE` - обход включён.
- `DISCONNECTING` - движки останавливаются.
- `BENCHMARKING` - выполняется тест или эволюционный поиск.
- `ERROR` - последняя операция завершилась ошибкой.

## DPI и стратегии zapret

Unlock не изобретает собственный формат конфигураций. Он читает поставляемые `general*.bat` из `bin/zapret/configs`, извлекает аргументы `winws.exe` и запускает их через встроенный движок.

В комплект входят:

- `winws.exe`.
- `WinDivert64.sys` и `WinDivert.dll`.
- TLS ClientHello и QUIC payload-файлы.
- Hostlist и ipset-файлы.
- Набор preset-конфигураций `general.bat`, `general ALT*.bat`, `general SIMPLE*.bat`, `general FAKE TLS*.bat` и другие варианты.

### Game mode

По умолчанию стратегия касается только нужных веб-портов. Game mode заменяет узкий диапазон на `1024-65535`, чтобы обходить ограничения в играх и голосовых сервисах. Это увеличивает объём анализируемого трафика, поэтому режим лучше включать только при необходимости.

После изменения Game mode работающий `winws.exe` перезапускается с новым набором аргументов.

## Telegram

Telegram-подсистема использует встроенный `tg-ws-proxy` и не требует отдельного ручного запуска прокси.

Поддерживается:

- локальный MTProto listener на `127.0.0.1:1443`;
- стабильный секрет, чтобы Telegram не получал новую ссылку после каждого запуска;
- генерация `tg://proxy?...` ссылки;
- повторная передача ссылки в Telegram Desktop;
- автоматическое предложение прокси при обнаружении запущенного Telegram;
- Fake TLS режим с SNI `www.microsoft.com`;
- fallback-поведение для неизвестного клиента, который подключается к локальному порту.

После включения Fake TLS старая ссылка Telegram становится недействительной, поэтому приложение предлагает подтвердить новую ссылку.

## VPN

VPN запускается отдельной кнопкой и не зависит от состояния DPI bypass. Внутри используются разные движки для разных задач:

| Движок | Назначение |
| --- | --- |
| sing-box | VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и транспортные варианты |
| wireproxy | WireGuard и AmneziaWG в режиме локального SOCKS/HTTP-прокси |
| AmneziaWG + Wintun | Полноценный TUN-адаптер, включая UDP-трафик |

Локальные порты VPN:

- SOCKS5: `127.0.0.1:2080`.
- HTTP proxy: `127.0.0.1:2081`.
- TUN-адрес: `172.19.0.1/30`.
- MTU TUN: `1400`.

### Импорт серверов

Можно вставить ссылку, загрузить файл, перетащить конфигурацию в окно или импортировать QR-код.

Поддерживаемые share link форматы:

| Формат | Схема |
| --- | --- |
| VLESS | `vless://` |
| VMess | `vmess://` с base64 JSON |
| Trojan | `trojan://` |
| Shadowsocks | `ss://` в SIP002 и base64-вариантах |
| Hysteria 2 | `hysteria2://` и `hy2://` |
| Amnezia VPN | `vpn://` с упакованной конфигурацией |

Для VLESS, VMess и Trojan распознаются TLS, REALITY, uTLS fingerprint, ALPN, WebSocket, gRPC, HTTP/2 и HTTP Upgrade параметры.

Также принимаются:

- WireGuard и AmneziaWG `wg-quick` `.conf`;
- конфигурации с IPv4 и IPv6 `AllowedIPs`;
- DNS, MTU, PersistentKeepalive и PresharedKey;
- AmneziaWG 1.0 и 2.0 параметры обфускации `Jc`, `Jmin`, `Jmax`, `S1-S4`, `H1-H4`, `I1-I5`;
- обычные текстовые подписки со списком ссылок;
- HTTPS-подписки размером до 4 MiB без автоматического следования редиректам;
- изображения PNG, JPG, JPEG, BMP, WEBP и GIF с QR-кодом.

QR-импорт является опциональным и требует `opencv-python-headless`.

## Benchmark

На первом запуске Unlock может предложить автоматическое тестирование. Benchmark по очереди запускает стратегии, проверяет доступность целевых сервисов и сохраняет результат.

Проверяются:

- Discord: основной сайт, gateway, CDN и updates;
- YouTube: основной сайт, короткие ссылки, изображения и video redirector;
- Google: основной сайт и `gstatic.com`;
- Cloudflare: основной сайт и CDN;
- TCP-задержка до публичных DNS-серверов `1.1.1.1`, `8.8.8.8`, `9.9.9.9`.

Для каждого HTTPS-адреса используются HTTP/1.1, TLS 1.2 и TLS 1.3. Ответы 4xx считаются доказательством успешного прохождения handshake, транспортные ошибки считаются блокировкой.

Побеждает самая быстрая стратегия, которая прошла полный набор проверок. Если полностью рабочей стратегии нет, приложение сохраняет вариант с лучшим количеством пройденных endpoints.

Benchmark можно отменить. При отмене Unlock прекращает повторные подсказки и позволяет выбрать стратегию вручную в Settings.

## Эволюция стратегии

Кнопка **Evolve a strategy for my provider** запускает генетический поиск.

Алгоритм:

1. Берёт рабочие preset-конфигурации как начальную популяцию.
2. Представляет каждую конфигурацию как набор безопасных генов DPI.
3. Создаёт новые варианты мутацией и crossover.
4. Проверяет кандидатов на Discord, YouTube, Google и Cloudflare.
5. Оставляет лучшие варианты и повторяет процесс несколько поколений.
6. Сохраняет победителя в пользовательское хранилище стратегий.

Ограничения поиска настроены так, чтобы один запуск укладывался примерно в 45 минут. Можно остановить поиск и сохранить лучший подтверждённый результат. Пользовательские стратегии хранятся отдельно от основной конфигурации, до 10 последних вариантов.

## Первое включение

1. Запустите Unlock.
2. Подтвердите запрос Windows UAC, если нужен DPI bypass или TUN.
3. Дождитесь первого benchmark либо выберите стратегию вручную.
4. Нажмите основную кнопку на Home.
5. При необходимости откройте Settings и включите Telegram, Game mode или VPN.

Если нужен только Telegram, DPI можно отключить. В этом случае приложение может работать без администратора, но обход системной DPI-блокировки через WinDivert недоступен.

## Установка готовой сборки

Сборка является one-folder приложением. Нельзя переносить только `Unlock.exe`, рядом с ним должна оставаться папка `_internal` со всеми ресурсами и встроенными сетевыми движками.

Пример установки:

1. Распакуйте содержимое `dist/Unlock` в отдельную папку.
2. Запустите `Unlock.exe`.
3. Разрешите повышение прав, если используете DPI или TUN.
4. Не удаляйте файлы из `bin` внутри каталога сборки.

One-folder выбран специально: сетевые бинарники не распаковываются заново во временную папку при каждом запуске, а Windows Defender реже блокирует их после ручного разрешения.

## Запуск из исходников

Требования:

- Windows 10 или Windows 11;
- Python 3.12 или совместимая версия;
- доступ к встроенным бинарникам из каталога `bin`;
- права администратора для WinDivert и TUN.

Установка зависимостей:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
```

Запуск:

```powershell
py main.py
```

Дополнительные аргументы:

```text
--minimized   запустить сразу в системном трее
--no-elevate  не выполнять повторный запуск через UAC
```

Если комплект `bin/zapret` отсутствует, его можно подготовить скриптом:

```powershell
py tools/fetch_zapret.py
```

## Сборка EXE

Для сборки установите PyInstaller:

```powershell
py -m pip install pyinstaller
pyinstaller unlock.spec --noconfirm
```

Результат:

```text
dist/Unlock/Unlock.exe
```

Spec-файл проверяет наличие `winws.exe`, preset-конфигураций, sing-box, wireproxy, AmneziaWG и Wintun. Без этих файлов сборка останавливается, чтобы не получить неполный дистрибутив.

## Хранение данных

Unlock не записывает пользовательскую конфигурацию рядом с EXE. Данные лежат в профиле Windows:

| Путь | Назначение |
| --- | --- |
| `%APPDATA%\\Unlock\\config.json` | Основные настройки и выбранная стратегия |
| `%APPDATA%\\Unlock\\vpn-config.json` | Сохранённые VPN-профили |
| `%APPDATA%\\Unlock\\vpn-wg.conf` | Временная конфигурация WireGuard для движка |
| `%APPDATA%\\Unlock\\vpn-tun.json` | Конфигурация TUN для sing-box |
| `%APPDATA%\\Unlock\\evolved-strategies.json` | Найденные генетическим поиском стратегии |
| `%APPDATA%\\Unlock\\logs\\unlock.log` | Журнал приложения |
| `%PROGRAMDATA%\\Unlock\\unlock.conf` | Конфигурация AmneziaWG-сервиса, доступная LocalSystem |

VPN-ссылки и конфигурации хранятся локально. Приватные ключи не отправляются разработчику.

## Безопасность и права

- WinDivert и TUN требуют Administrator rights.
- Приложение не запускает одновременно несколько копий: повторный запуск передаёт уже открытой копии команду показать окно.
- При аварийном завершении приложение пытается восстановить системный прокси и остановить оставшийся VPN-интерфейс.
- HTTPS-подписки принимаются только по HTTPS, ограничены по размеру и не переходят по редиректам автоматически.
- Приватные ключи WireGuard используются для запуска локального туннеля и сохраняются в пользовательском профиле.
- Сетевые тесты benchmark обращаются только к перечисленным в коде целевым сервисам и публичным DNS-адресам.
- Встроенные сторонние компоненты поставляются вместе с их лицензиями, включая MIT-лицензию `unlock/tgwsproxy/LICENSE`.

## Ограничения

- Приложение предназначено для Windows и использует WinDivert, Wintun и Windows system proxy API.
- Работоспособность DPI-стратегии зависит от конкретного провайдера, региона и времени.
- TUN и WireGuard требуют корректных прав и доступного сетевого драйвера.
- Некоторые VPN-ссылки могут содержать параметры, которые не поддерживаются upstream-движком.
- QR-импорт требует дополнительного пакета OpenCV.
- Benchmark не заменяет измерение скорости загрузки: он оценивает успешность handshake, задержку probe и TCP RTT.

## Архитектура

```text
main.py
  |
  +-- unlock.controller.Controller
  |     +-- DpiEngine -> bin/zapret/winws.exe + WinDivert
  |     +-- TelegramProxy -> unlock/tgwsproxy
  |     +-- VpnEngine -> sing-box / wireproxy
  |     +-- AwgEngine -> AmneziaWG + Wintun
  |     +-- Benchmark / Evolution workers
  |
  +-- unlock.ui.main_window.MainWindow
        +-- Home
        +-- VPN
        +-- Settings
        +-- Logs
        +-- system tray
```

Основные модули:

- `unlock/controller.py` - состояния, фоновые потоки и координация движков.
- `unlock/dpi_engine.py` - запуск и остановка WinDivert/winws.
- `unlock/strategies.py` - разбор preset `.bat` и хранение evolved-стратегий.
- `unlock/benchmark.py` - сетевые probes и выбор лучшей конфигурации.
- `unlock/evolution.py` и `unlock/genome.py` - генетический поиск параметров.
- `unlock/telegram_proxy.py` - локальный Telegram bridge.
- `unlock/vpn_links.py` и `unlock/vpn_import.py` - парсинг ссылок, файлов, подписок и QR.
- `unlock/vpn_engine.py` - SOCKS, HTTP и TUN режимы VPN.
- `unlock/ui/` - PyQt6 интерфейс, темы, анимации и диалоги.

## Частые проблемы

### Unlock не включает DPI

Перезапустите приложение от имени администратора или разрешите UAC. Проверьте наличие `bin/zapret/WinDivert64.sys`, `WinDivert.dll` и `winws.exe`.

### VPN сохраняется, но не подключается

Проверьте, что в каталоге сборки есть нужный движок:

- `bin/sing-box/sing-box.exe` для VLESS, VMess, Trojan, Shadowsocks и Hysteria2;
- `bin/wireproxy/wireproxy.exe` для WireGuard в proxy-режиме;
- `bin/amneziawg/amneziawg.exe` и `bin/amneziawg/wintun.dll` для TUN.

### Telegram не принял ссылку

Нажмите предложение прокси повторно на Home или выключите и снова включите WebSocket bridge. При включённом Fake TLS Telegram получает новую ссылку после смены режима.

### Benchmark не нашёл рабочую стратегию

Попробуйте другую сеть, включите Game mode только при проблемах с играми и выберите preset вручную в Settings. Эволюционный поиск может найти вариант, которого нет среди стандартных конфигураций.

### Окно не появляется

Проверьте системный трей: Unlock продолжает работать после закрытия окна. Повторный запуск передаёт первой копии команду показать интерфейс.
